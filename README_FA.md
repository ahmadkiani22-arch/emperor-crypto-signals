# امپراتور تریدر — وب‌اپ اندروید

نسخه اولیه وب‌اپ برای موبایل. فایل‌ها باید روی یک میزبان HTTPS قرار بگیرند تا قابلیت افزودن به صفحه اصلی و Service Worker فعال شود.

## فایل‌ها
- `index.html`: رابط فارسی و راست‌چین
- `app.js`: دریافت داده نوبیتکس و منطق ایچیموکو/RSI/حجم/ATR
- `manifest.json`: مشخصات وب‌اپ
- `sw.js`: کش پوسته برنامه

## منطق نمونه
- خرید احتمالی: قیمت بالای ابر، تنکان بالای کیجون، RSI بین ۵۲ تا ۷۰، حجم بیش از ۱.۱۵ برابر میانگین ۲۰ کندل.
- فروش احتمالی: قیمت زیر ابر، تنکان زیر کیجون، RSI بین ۳۰ تا ۴۸، حجم بیش از ۱.۱۵ برابر میانگین.
- کندل آخر برای کاهش سیگنال ناپایدار حذف می‌شود.
- حد ضرر بر اساس سقف/کف ۱۲ کندل و ۱.۵ ATR؛ هدف‌ها ۱.۵R و ۲R.
- این نسخه ابر را به‌صورت محاسبه ساده‌شده در لحظه می‌سنجد و چیکو اسپن را به کار نمی‌گیرد.
- ارزش موقعیت تخمینی است؛ نرخ تبدیل تومان/تتر، کارمزد، هزینه تعهدی، لغزش و لیکوییدشدن در آن لحاظ نشده.
- API یا سیاست CORS می‌تواند دسترسی مرورگر را محدود کند. در صورت خطا، نیاز به یک واسط امن سمت سرور است؛ هیچ کلید خصوصی‌ای را در فایل مرورگر قرار ندهید.
- داده رایگان و عمومی تضمین دسترس‌پذیری دائمی ندارد. قبل از استفاده واقعی بک‌تست و paper trading انجام شود.
